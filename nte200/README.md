# NTE200 — интерактивный каталог запчастей (публикация)

Готовый к публикации сайт каталога запчастей карьерного самосвала **NTE200** (NHL):
самосвал, привод **GE**, двигатель **Cummins QSK50** (из книги PDF и из онлайн‑каталога
Cummins), цены и руководства по ремонту/эксплуатации.

> **Это ветка публикации (`main`).** Здесь лежит только сам сайт — плоская раскладка
> в корне репозитория, чтобы Vercel раздавал его без настройки. Исходники, скрипты
> пересборки, прайс‑лист и документация — в ветке **`rawdata`**.

## Состав

```
index.html · app.js · styles.css      сайт (без внешних зависимостей)
data/     parts.js · prices.js · manuals.js · all_part_numbers.csv
drawings/ чертежи (415 файлов; QO-*.png — листы онлайн‑каталога QSK50)
manuals/  PDF-руководства (ремонт, оператор, электросхема 24В)
vercel.json  заголовки кэширования
```

Двигатель QSK50 представлен двумя наборами глав: **Q01–Q12** — из книги (PDF), и
**QO01–QO14** — из онлайн‑каталога Cummins (с массой, габаритами, характеристиками
и фото деталей; фото грузятся с публичного CDN Cummins).

## Публикация на Vercel

Импортируйте репозиторий в Vercel и деплойте ветку `main` — фреймворк не нужен
(**Framework Preset: Other**), сборка не требуется, корневая папка — корень репозитория.
`vercel.json` задаёт долгий кэш для чертежей/руководств.

Локально сайт открывается двойным щелчком по `index.html` — без сервера и интернета
(офлайн не грузятся только фото деталей с CDN Cummins).

Исходники и скрипты — в ветке [`rawdata`](../../tree/rawdata):
