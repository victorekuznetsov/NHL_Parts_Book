# Каталог запасных частей Cummins — публикуемая версия (Vercel)

Статический онлайн-каталог запчастей двигателей Cummins, собранный из
официального каталога **parts.cummins.com** по серийным номерам (ESN).
Оформление — фирменный стиль «Развитие», светлая и тёмная тема.

Это **ветка `main`** — только то, что нужно для публикации на Vercel:
страница каталога, данные двигателей и чертежи. Фотографии деталей
подгружаются напрямую с публичного CDN Cummins, поэтому в деплой не
кладутся десятки тысяч файлов.

Вся исходная выгрузка, сырые данные `data/<ESN>/`, скрипты сборки
(`crawler.py`, `crawl_details.py`, `tools/`) и брендбук — в ветке
**`rawdata`**.

По вопросам работы каталога, ошибок и замечаний — Кузнецов В.Е.,
KuznetsovVE@industrservice.ru

## Что внутри

```
index.html · app.js · styles.css   оболочка каталога (статическая)
engines.js                          список двигателей для переключателя
data/<ESN>.js                       состав каждого двигателя (window.CATALOGS)
drawings/<ESN>/*.png                чертежи узлов (локально)
brand/                              логотипы «Развитие» (свет/тёмная тема)
vercel.json                         конфигурация статического деплоя
```

Фотографии деталей грузятся с `parts.cummins.com/graphics/parts/...`
(публично, без авторизации). Если фото недоступно — оно просто не
показывается, остальной каталог работает.

## Возможности

- Переключатель двигателей; поиск по номеру, наименованию и заменённым
  (старым) номерам сразу по всем двигателям.
- Чертёж рядом со списком позиций; карточка детали (фото, масса и габариты,
  цепочка замен номера, где применяется).
- Заказ с выгрузкой в CSV и печатью; сохраняется в браузере.
- Выгрузка всех номеров модели / всех каталогов в Excel, проверка списка
  номеров на наличие, загрузка цен из файла.
- Светлая и тёмная тема (переключатель в шапке).

## Деплой на Vercel

Статический сайт, сборка не нужна. Vercel обслуживает файлы из корня
репозитория; `vercel.json` задаёт заголовки кеширования. Достаточно
подключить репозиторий (ветка `main`) — Framework Preset: **Other**,
Build Command: пусто, Output Directory: пусто (корень).
