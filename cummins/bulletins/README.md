# Технические бюллетени Cummins — слепок папок

Здесь должны лежать PDF-бюллетени/сервисные темы, на которые ссылаются карточки
деталей трёх наших двигателей (NTE240 · ESN 33239746, NTE200 · ESN 33239899,
TR100A · ESN 37295879). Cummins **не публикует** эти документы в открытом
доступе — их видно только на `quickserve.cummins.com` под дилерским логином.
Автоматизировать вход туда мы сознательно не стали (SSO/защита от ботов, риск
для аккаунта) — заходите и скачивайте сами, а файлы кладите по этой схеме.

## Структура

- `general/3666132.pdf` — единственный бюллетень из карточек деталей, который
  в принципе существует как общедоступный документ (общий бюллетень «Cummins
  Coolant Requirements and Maintenance», упоминается в NTE240 и NTE200). Я не
  нашёл официальную прямую ссылку на cummins.com — только сторонние
  дилерские копии, которым не доверяю без проверки. Проще всего скачать его
  заодно на QuickServe (или у любого официального дилера Cummins) и положить
  сюда.
- `topics/<код>.pdf` — по одному файлу на каждый уникальный код темы/бюллетеня
  из карточек деталей. Список кодов и куда каждый класть — в `manifest.csv`
  (256 строк: код, тип, какие двигатели его используют, сколько деталей на
  него ссылаются, примеры номеров деталей и точный путь файла).
- `truncated.csv` — 174 детали, у которых в исходных данных список тем
  обрезан (Cummins в источнике хранит только первый код, если тем несколько).
  Для этих деталей на QuickServe нужно открыть карточку самой детали и
  посмотреть полный список — код из `manifest.csv` для них неполный.

## Про ссылки в манифесте

В `manifest.csv` (и `truncated.csv`) на каждую позицию есть **два столбца-ссылки**:

- **«Поиск в Google»** — сразу открывает поиск по коду ("Cummins <код> bulletin
  filetype:pdf"). Реально работающая ссылка, но не гарантирует, что нужный PDF
  найдётся в открытом доступе — для внутренних кодов Service Topic (не TSB…)
  чаще всего не найдётся, потому что Cummins их не публикует.
- **«QuickServe (войти и искать код вручную)»** — просто адрес
  `quickserve.cummins.com`, без подстановки кода. Прямых ссылок на конкретный
  документ у QuickServe нет: сайт отвечает редиректом на логин на любой путь
  и параметры, даже правдоподобно выглядящие — я проверил, готовых
  deep-ссылок туда не существует. Так что на самом QuickServe код придётся
  вставить в поиск руками после входа.

## Как пользоваться

1. Откройте `manifest.csv` в Excel.
2. Для нужных вам кодов (необязательно всех 256 — можно начать
   с самых частых, отсортируйте по столбцу «Деталей») кликните «Поиск в
   Google» или зайдите на QuickServe и найдите документ по коду / по одному
   из примеров деталей, скачайте PDF.
3. Сохраните файл ровно под именем из столбца «Куда положить файл»
   (например `cummins/bulletins/topics/TSB210209.pdf`).
4. Пришлите скачанные файлы мне (или сложите в эту папку и закоммитьте) —
   я подключу их к карточкам деталей в каталоге (ссылка «Бюллетень» рядом с
   характеристиками детали).

Скачивать все 256 не обязательно и не обязательно сразу — присылайте, что
есть, я буду добавлять по мере поступления.
