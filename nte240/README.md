# NTE240 — интерактивный каталог запасных частей (публикация)

Готовый **самодостаточный** веб-каталог запчастей самосвала **NHL NTE240** с
подробным каталогом двигателя **Cummins QSK60**. Ветка `main` содержит только
сам сайт (корень репозитория = корень сайта) и предназначена для публикации на
**Vercel** — сборка не требуется, всё работает как статические файлы.

## Публикация на Vercel

- Framework preset: **Other** (статический сайт, без сборки).
- Build Command: пусто. Output/Root Directory: **корень репозитория** (`/`).
- `index.html` уже лежит в корне — Vercel отдаёт его как главную страницу.
- `vercel.json` задаёт долгий кэш для картинок, а для `.js`/`.css`/`.html` —
  проверку актуальности при каждом запросе (чтобы обновления сайта подхватывались
  без ручного сброса кэша).

Открыть локально: `index.html` двойным щелчком (работает из `file://`).

## Что внутри

- `index.html`, `app.js`, `styles.css`, `gate.js` — основной каталог NTE240
  (поиск, заказ-спецификация, обновление цен, **проверка списка номеров** с
  выгрузкой результата в Excel).
- `data/` — данные каталога (`parts.js`, `prices.js`, `service.js`).
- `drawings/`, `service_media/`, `manual_media/` — иллюстрации.
- `manual.html` — руководство оператора NTE240 целиком (собирается из
  заводского `NTE240 Driver's Manual-Polyus.docx` скриптом
  `build/gen_nte240_manual.py`; иллюстрации — `manual_media/`, включая
  пиктограммы внутри таблиц).
- `service.html`, `service/`, `service_media/` — **70 инструкций по ремонту и
  обслуживанию** по разделам каталога, из перевода заводского руководства
  «俄罗斯NTE240维修手册-2023-译文». Названия разделов — русские, из оглавления
  того же руководства; спецификации к рисункам, моменты затяжки, перевод
  единиц и массы узлов — настоящие таблицы (структура из исходных файлов
  Word). Пересобираются `build/gen_nte240_service.py` и
  `build/gen_service_tables.py`.
- `manuals.html`, `manuals/`, `data/manuals.js` — заводские руководства в PDF:
  **Руководство по сборке** (47 с.) и **Инструкция по сварке кузова** (30 с.).
- **`engine/`** — подробный каталог двигателя **Cummins QSK60** (ESN 33239746,
  CPL 3451): 92 системы, 1041 деталь, чертежи узлов, фотографии и характеристики
  деталей, цены (CNY) из прайса NTE240. Открывается кнопкой «🛠 Каталог двигателя
  QSK60 (Cummins)» в шапке и ссылкой в разделах главы 700. У 8 узлов, для которых
  Cummins не публикует чертёж, чертёж дополнен из PDF-каталога (с пометкой).
  Глава 700 самого каталога NTE240 — «Двигатель Cummins QSK60 (из PDF)».

## Пароль и срок действия

`gate.js` в корне и в `engine/` больше не активны — доступ ко всему каталогу
(включая эту папку) проверяется на сервере через корневой `middleware.js` +
`auth/`, единым логином на весь домен. Управление логинами и паролями —
`node build/make_user.mjs set|del|list` в корне репозитория; пароли нигде не
хранятся в открытом виде.

## Исходники и инструменты сборки

Исходные файлы Word/PDF в ветке `main` намеренно не лежат (чтобы деплой
оставался лёгким) — они в ветке **`rawdata`**:

- `NTE240 Driver's Manual-Polyus.docx` — руководство оператора;
- `俄罗斯NTE240维修手册-2023-译文.zip.001` + `.002` — перевод заводского
  руководства по ремонту 2023 года, по файлу на раздел (архив в формате
  Deflate64: `pip install zipfile-deflate64`);
- `nte240/Руководство по сборке_240.pdf`, `nte240/Руководство по сварке_NTE240.pdf`.

Пересборка из корня репозитория (нужен LibreOffice):

```
python3 build/gen_nte240_manual.py  "NTE240 Driver's Manual-Polyus.docx"
python3 build/gen_nte240_service.py <папка с главами руководства по ремонту>
python3 build/gen_service_tables.py <та же папка>     # текст -> настоящие таблицы
node     build/gen_kb.js /путь/к/Cummins_Parts_Book   # подхватит их в базу знаний
node     build/gen_part_docs.js                       # ссылки в «Проверить список»
```
