# Каталог запасных частей NHL TR100A (публикуемая версия, Vercel)

Интерактивный онлайн-каталог запчастей карьерного самосвала **NHL TR100A**:
шасси и кузов, двигатель **Cummins QST30 CM552**, инструкции по обслуживанию
и ремонту. Статический сайт без сборки и сервера.

Это **ветка `main`** — только то, что нужно для публикации на Vercel.
Все исходные материалы (Part Book, Engine Parts, прайс-листы `.xlsx`,
руководства по ремонту, шаблон бренда) и скрипты сборки — в ветке **`rawdata`**.

## Что внутри

```
index.html · app.js · styles.css     основной каталог машины (схема figures)
data/parts.js                        кузов/шасси TR100A (window.CATALOG)
data/engine.js                       двигатель QST30 из PDF (window.ENGINE) — глава «QST30»
data/service.js                      инструкции по ТО и ремонту (window.SERVICE)
data/prices.js                       цены (window.PRICES)
data/all_part_numbers.csv            все уникальные артикулы со всеми аналитиками
drawings/ · engine/ · service/       иллюстрации (локально)

qst30-cummins/                      ⟵ отдельный раздел: каталог двигателя QST30,
  index.html · app.js · styles.css     выгруженный с сайта parts.cummins.com по
  engines.js · data/37295879.js        ESN 37295879 (схема CATALOGS) — цены, фото
  drawings/37295879/*.png              деталей с CDN Cummins, цепочки замен номера
  brand/
vercel.json                          конфигурация статического деплоя
```

## Два взгляда на двигатель QST30

| Где | Источник | Что даёт |
|---|---|---|
| Глава **QST30** в каталоге машины | PDF «Engine Parts Information QST30» | 79 узлов, экспло-схемы, 0 потерянных номеров |
| Раздел **`/qst30-cummins/`** | Выгрузка с **parts.cummins.com** (ESN 37295879) | цены, фото деталей (CDN), цепочки замен, группировка по системам |

Из главы «QST30» в каталоге машины есть ссылка «↗ Открыть каталог QST30 с сайта
Cummins», из раздела Cummins — ссылка назад «← Каталог машины TR100A».
PDF-каталог двигателя оставлен как есть; недостающие в Cummins-выгрузке чертежи
узлов **дополнены** чертежами из PDF (в карточке узла — пометка источника).

## Цены

Цены (CNY, без НДС) — **только из прайс-листов песочницы TR100** («ГЕ на
согласование» + «…31.07.2026», новый перекрывает старый). Запечены/наложены в
оба каталога. Покрытие частичное; позиции без цены помечены «—» / «уточняется».

## Деплой на Vercel

Статический сайт, сборка не нужна. Framework Preset: **Other**, Build Command
и Output Directory — пусто (корень), ветка `main`. Основной каталог — `/`,
каталог QST30 с сайта Cummins — `/qst30-cummins/`.
